# pacemanbot

本插件基于 Astrbot 开发

## 功能

1. /register 用户名-将玩家 IGN 和 QQ 号绑定；PaceMan 或 MCSR Ranked 能查到即可注册
2. /paceman [用户名]-查询某玩家的 24 小时数据（不添加用户名则查询自己）
3. /run [用户名]-查询某玩家最近一次完成的速通数据（不添加用户名则查询自己）
4. /rank [用户名]-查询某玩家 rank 数据（不添加用户名则查询自己）
5. /ldb [cn]-查询本赛季 MCSR Ranked 榜单前 20 名（不添加参数查全球，添加 cn 查中国）
